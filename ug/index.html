Rufus for Linux

Create bootable USB drives and disk images

 

Rufus for Linux is a utility that helps format and create bootable USB flash drives and disk images, such as USB keys/pendrives, memory sticks, etc.

بۇ ئەھۋاللار ئۈچۈن ئالاھىدە پايدىلىق بولىدۇ:

  • you need to create USB installation media from bootable ISOs (Linux, UEFI, etc.)
  • قاچىلىمىغان سىستېما ئۈستىدە خىزمەت قىلىشىڭىز كېرەك
  • you need to create a disk image that you can boot in QEMU, KVM or Hyper-V
  • تۆۋەن دەرىجىلىك ئۈسكۈنىلەرنى ئىجرا قىلغۇڭىز بار

Rufus for Linux is device-first: pick a real USB drive to format it through pkexec, or pick an image file to create a bootable image without any privileges.

Despite its small size, Rufus for Linux provides everything you need!

Supported formats and options:

  • File systems: FAT32, ext2/ext3/ext4 (built-in), exFAT and NTFS (via the host mkfs tools)
  • Partition schemes: MBR and GPT, with the 2048 sector alignment of Windows Rufus, or 2272 for old BIOS fixes
  • Bootloader: SYSLINUX v6 BIOS bootloader, installed to the MBR and the FAT32 partition boot record
  • Image containers: raw, fixed VHD (native) and VHDX (via qemu-img)
  • Advanced format options: bad block scan, full format, extended label and icon files, casper persistence, dirty-cow scrub pass
  • Verify written data, and compute SHA-1 or SHA-256 checksums

A non exhaustive list of the ISO images Rufus for Linux is known to work with is also provided at the bottom of this page. (1)

سىستېما تەلىپى:

A C11 compiler, the GTK 3 or GTK 4 development headers, GNU Make and the gettext tools. On Debian/Ubuntu, this amounts to:

$ sudo apt install build-essential libgtk-4-dev gettext

Once built, the application is ready to use. Formatting a real device additionally requires pkexec (polkit), while image files need no privileges at all.

ئىشلىتىش مىقدارى

Rufus for Linux is built from source. Clone the repository, then compile and install it:

$ git clone https://github.com/0peratorXXX/rufusforlinux
$ cd rufusforlinux/linux && make
$ sudo make install PREFIX=/usr/local

This installs the four binaries:

  • rufus-gui – the GTK graphical front-end
  • rufus-format – the formatting engine
  • rufus-copy – the ISO and disk image writer
  • rufus-devlist – the device discovery tool

Run man rufus-gui, man rufus-format, man rufus-copy and man rufus-devlist for the full option reference.

Notes on privileges:

Selecting a real USB drive launches the formatting engine through pkexec, so you will be prompted for an administrator password. Mounted partitions are unmounted automatically, or you are warned before they are wiped.

Creating an image file instead of formatting a device requires no privileges at all.

ISO قوللاشقا دائىر ئىزاھاتلار:

Rufus for Linux allows the creation of a bootable USB drive or disk image from an ISO image (.iso).

Creating an ISO image from a physical disc or from a set of files is very easy to do however, through the use of a disc burning application such as the freely available xorriso, or with dd.

Rufus for Linux is produced in a 100% transparent manner, from its public source, using a GNU/Linux environment (C11, GTK and GNU Make).

Rufus for Linux is a native port of Rufus, which was created by Pete Batard, and the third-party sources it bundles retain their own licensing.

كۈندىلىك خاتىرىنى يېڭىلاش

  • (2026.09.13) 0.1.0 نەشىرى
    • Add a GTK graphical interface, which also compiles cleanly against GTK 3.
    • Add the rufus-format, rufus-copy and rufus-devlist command line engines.
    • Add FAT32 and ext2/ext3/ext4 formatting, with exFAT and NTFS delegated to the host mkfs tools.
    • Add MBR and GPT partition schemes, using the 2048 sector alignment of Windows Rufus, or 2272 for the old BIOS fixes.
    • Add SYSLINUX v6 BIOS bootloader installation (MBR and FAT32 partition boot record).
    • Add casper persistence support (persistence.conf on ext file systems, loopback casper-rw file on FAT32).
    • Add raw, fixed VHD and VHDX image containers, for use with QEMU, KVM or Hyper-V.
    • Add the advanced format options: bad block scan, full format, extended label and icon files, and dirty-cow scrub pass.
    • Add byte-for-byte verification of written data, plus SHA-1 and SHA-256 checksums.
    • Add light and dark themes, progress reporting and cooperative cancellation.
    • Add make deb and make dist packaging, man pages, a desktop entry and AppStream metainfo.
    • Add French and German translations.
